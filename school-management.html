School Structure

Classes 1–12, each split into Sections A, B and C. Every section holds 30 students, giving 90 students per class and 1,080 students school-wide. Each account gets an auto-generated ID and password in the format First 4 letters of name + @ + Role Code + 3-digit serial (e.g. Bala@STU001).
